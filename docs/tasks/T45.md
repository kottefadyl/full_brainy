Statut : prévue

**T45 — Paquets de domaine partageables** · Dépendances : T14, T17, T24, puis T35 à T39 selon le contenu.
- Format de paquet versionné contenant formats de données, unités locales, listes de codes, objets d'exemple, opérations configurées, vues, textes EN/FR et notice. **Jamais** de code exécutable, de données d'utilisateur ni de pièces privées (règle 17).
- Installation = copie locale avec aperçu des dépendances et des conflits (mécanique de T14 et T17). Retirer un paquet le détache sans supprimer les entrées. Les mises à jour sont proposées, jamais imposées.
- Provenance : auteur, version, date, licence ; signature facultative. Import par fichier ou lien ; pas de place de marché publique dans cette tâche.
- Les modèles de départ de T24 adoptent ce format (ajustement A8).
- Paquets pilotes : Notes et Liens, Dépenses, Ventes simples, Météo locale, Boutique, Suivi de mesures. Ce sont des experts de chaque domaine qui doivent pouvoir en créer de nouveaux, sans modifier le noyau de Brainy.
- **Terminé quand :** un paquet exporté d'un compte s'installe dans un autre avec aperçu ; aucune donnée utilisateur n'est exportée ; désinstaller conserve les entrées ; une version incompatible est refusée clairement ; les six paquets pilotes passent leurs scénarios de référence.
