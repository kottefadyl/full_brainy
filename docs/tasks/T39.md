Statut : prévue

**T39 — Listes de codes et classifications** · Dépendances : T04, T05, T17, T37.
- Champ à vocabulaire contrôlé, éventuellement hiérarchique : code stable, libellés EN/FR (et autres), état actif ou obsolète. Les listes sont **locales à une collection** (règle 1) ; des listes de départ (pays, devises, niveaux scolaires…) sont des modèles copiés localement. Import d'une classification depuis CSV avec aperçu et extension T07 (ajustement A10).
- Changer un libellé ne change pas le code stocké. Un code obsolète reste lisible dans les entrées existantes. Fusion de codes avec aperçu et migration contrôlée.
- Les agrégats de T35 peuvent regrouper à un niveau choisi de la hiérarchie.
- **Terminé quand :** une classification à trois niveaux sert à saisir et regrouper des entrées démographiques ; renommer un libellé conserve les entrées ; un code obsolète reste visible ; l'import CSV signale les erreurs ligne par ligne ; la copie vers une autre collection passe par un aperçu. Scénarios R8 et R9.
