**T46 — Mode tableur des vues tableau** · Dépendances : T03 (vues enregistrées), T04 (édition d'un format de données).
- Demande produit (10 novembre 2026) : les personnes habituées aux tableurs (Baserow, NocoDB, Airtable) saisissent et modifient leurs données comme dans une feuille, **uniquement dans une vue tableau et quand le mode est activé**. Ajouter une colonne garde le choix explicite de l'unité.
- Une feuille porte **un seul format de données** : toutes ses colonnes sont les champs de ce format (pas seulement les colonnes de la vue). Une vue à plusieurs formats propose un choix du format de la feuille.
- Cellule : mêmes règles que le formulaire d'entrée (virgule décimale, dates, heures, durées, liens, caractère, choix). Une modification renvoie toutes les autres valeurs de l'entrée inchangées et la version attendue. Les types complexes (pièce jointe, référence, mesure, code, lieu, choix multiples), l'état d'un flux, une entrée de registre, hors ligne ou en ajout seul s'ouvrent dans le formulaire complet.
- Colonne ajoutée = champ ajouté au format de données (mêmes contrôles que l'éditeur ; 30 champs ; nom unique). Pour un nombre, **aucune unité n'est présélectionnée** : il faut choisir une unité ou « Sans unité ». Les autres types renvoient à l'éditeur du format de données.
- **Terminé quand :** sur web et Flutter, on modifie une cellule, ajoute une ligne et une colonne de nombre avec unité, sans perdre les autres valeurs ; une valeur invalide reste affichée avec la raison.
