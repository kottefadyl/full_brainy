**T42 — Registre non modifiable** · Dépendances : T26, T28, T29.
- Mode facultatif d'un format de données ou d'une collection : **ajout seul**. Une correction est une nouvelle entrée liée à l'originale (contre-écriture). Les soldes et stocks courants restent dérivés.
- Traçabilité : chaîne de hachage ou signature pour détecter une altération, action « Vérifier l'intégrité » et export de preuve lisible.
- Conservation et effacement : décision produit requise pour concilier non-modification et droit à l'effacement (par exemple anonymiser les champs personnels en conservant les montants, ou supprimer avec trace). Ne pas promettre de conformité légale (règle 15).
- Migrer les mouvements de stock de T26 vers ce mode, ou garantir qu'ils partagent son contrat (ajustement A5).
- **Terminé quand :** modifier ou supprimer directement une écriture du registre est refusé par l'API ; une correction apparaît comme écriture liée ; une altération en base, simulée en test, est détectée ; un stock et une caisse simple se reconstruisent depuis leurs écritures ; la documentation précise qu'il ne s'agit pas d'une certification comptable, médicale ou réglementaire. Scénarios R4 et R7.

**Livraison :** contrat [T42_REGISTRE.md](../T42_REGISTRE.md) ; mode facultatif `appendOnly` sur format de données vide, écritures et contre-écritures liées, chaîne de hachage avec tête, vérification et preuve exportable ; masquage des champs choisis avec montants conservés et trace chaînée (décision produit du 2026-10-29). Les mouvements T26 reçoivent une chaîne par produit et un scellement explicite ou lors du prochain mouvement de leur historique antérieur. API, web et Flutter proposent les actions EN/FR.

**Vérification :** `npm run typecheck` API ; `docker compose exec -T api npm run smoke:ledger` : caisse R4, stock/lot R7, correction, effacement, sauvegarde, reconstruction des soldes et altérations directes détectées. Limites : pas de transaction Mongo multi-document dans le déploiement local, pas de migration automatique d'un format de données déjà rempli, pas de certification.
