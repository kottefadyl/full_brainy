- **API** : `domestic-templates.ts` (données des modèles, thèmes), `domestic-template.setup.ts` (création générique : objets puis références, vues, stock, planificateur, totaux). `starterTemplates` renvoie `group` et `groupName`, triés par thème (« Partir de zéro » reste premier). Le planificateur T49 est ouvert aux modèles `tasks`, `habits`, `home`, `garden` (`PLANNER_TEMPLATES`, `task-planner.rules.ts`). Fumée : `npm run smoke:domestic-templates` (18 modèles en EN et FR, habitude quotidienne dans l'agenda).
- **Web** : `starter-dialog.tsx` (sections par thème, icône par modèle), `lib/collection-identity.tsx` (18 icônes).
- **Flutter** : `starter_dialog.dart`, `collection_identity.dart`, `collections_api.dart` ; test `visual_flows_test.dart`.

Limites : pas encore de vue « Bientôt » (expirations, garanties, péremptions, rappels à venir) ; pas de rappel annuel automatique des anniversaires ; consommation de carburant non calculée d'office (une formule peut être ajoutée) ; les montants n'ont pas d'unité monétaire imposée.
