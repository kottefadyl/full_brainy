**T48 — Aperçu des liens conservés** · Dépendances : T24 (modèles), T25 (liens conservés).
- Demande produit (11 novembre 2026) : dans une collection créée depuis le modèle « Liens conservés », un lien enregistré affiche un aperçu du site ou du contenu (image, titre, description, site), comme dans une messagerie, **seulement quand la valeur saisie est un lien web**.
- **Terminé quand :** un lien YouTube montre sa miniature avec un bouton lecture, son titre et sa chaîne ; une page ordinaire montre son titre Open Graph ; une adresse sans page HTML affiche seulement son site ; les autres collections n'affichent pas d'aperçu ; l'API refuse les adresses privées, locales ou non web.

Implémentation :
- API : `link-preview.fetch.ts` (requête sûre : http/https sur ports 80/443, pas d'identifiants dans l'adresse, IP résolue vérifiée à chaque connexion et redirection — réseaux privés, boucle locale, métadonnées cloud et IPv6 locaux refusés —, 3 redirections, 5 s, 512 Kio par page, 600 Kio par image), `link-preview.service.ts` (Open Graph, Twitter, `<title>`, oEmbed YouTube ; image recopiée en `data:` pour que les clients ne contactent pas le site ; cache MongoDB `link_previews` 7 jours, 6 h après un échec ; 30 nouvelles requêtes par minute et par personne), requête `linkPreview(url)` réservée aux comptes connectés. Toutes les collections créées depuis un modèle gardent désormais `templateId` (provenance, pas un type). Fumée `npm run smoke:link-preview` (accès Internet nécessaire).
- Web : `lib/link-preview.ts`, `app/link-preview-card.tsx`, `app/link-preview.css`, branché dans `entry-card.tsx` ; chargement à l'apparition à l'écran, une requête par adresse, ouverture dans un nouvel onglet (`noopener`).
- Flutter : `lib/link_preview_card.dart`, emplacement `attachment` de `workspace_entry_row.dart`, une ligne dans `workspace_screen.dart` ; ouverture dans l'application externe. Aperçu natif `tool/link_preview_preview.dart`.

Validé le 2026-11-11 : `npm run typecheck`, fumées `smoke:link-preview`, `smoke:book`, `smoke:fitness` et analyse ; web `lint`, `tsc`, `build` ; parcours Edge réel (5 liens dont le Short YouTube de la demande, collection Notes sans aperçu, 390 px sans défilement horizontal, aucune erreur console) ; `dart analyze`, 7 tests `link_preview_test.dart` et 43 tests associés ; rendu natif Windows clair/sombre 390 et 1100 px.
