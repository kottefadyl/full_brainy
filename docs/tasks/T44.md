**T44 — Données lourdes par référence** · Dépendances : T07, T30, T31.
- Stockage objet compatible S3 (ou équivalent) pour les pièces volumineuses ; envoi par morceaux avec reprise ; l'entrée garde les métadonnées (nom, taille, empreinte, format, date) et un identifiant ; téléchargement par lien signé de courte durée réservé au propriétaire ou à un droit T28 ; vérification d'intégrité.
- Les limites de 2 MiB par fichier et 8 MiB par entrée subsistent pour les petites pièces ; documenter le seuil qui bascule vers ce mode.
- Brainy **catalogue et référence** les jeux de données lourds (génomique, rasters, séries brutes) mais ne les analyse pas : passer par une intégration.
- Détection de fichier manquant ; l'export liste les références et indique comment récupérer les fichiers.
- **Terminé quand :** un fichier de plusieurs centaines de Mo s'attache avec reprise après coupure ; l'intégrité est vérifiée ; un autre compte ne peut pas le lire ; l'export documente les références ; aucun client ne charge le fichier entier en mémoire. Scénario R6.
