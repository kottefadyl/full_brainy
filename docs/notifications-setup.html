Brainy notifications: setup procedure

How to make reminders ring on Android phones (free, with Firebase Cloud Messaging) and, if you wish, send them by email (free, with Brevo). Written on 12 November 2026.

Already done in the code

  • Reminder notifications are sent with high priority and sound.
  • The Android app creates a “Rappels / Reminders” channel that rings, vibrates and pops up on screen, and asks for the notification permission required by Android 13 and later.
  • The API has a protected address, /cron/reminders, that a free outside service can call every minute so reminders also work on Vercel’s free plan.
  • The Firebase project brainy-6d65c exists and the Android app is registered in it (google-services.json is in the app).

What is left needs your accounts and a real phone: follow the parts below.

Part 1 · Required

Push notifications on your computer and phone

  1. Open console.firebase.google.com and choose the project brainy-6d65c.
  2. Click the ⚙ gear, then Project settings, then the Service accounts tab.
  3. Click Generate new private key, then Generate key. A .json file is downloaded.
    This file is a password for your Firebase project. Never send it to anyone and never put it inside the project folder.
  4. Move it to a private folder, for example C:\Users\carefull\secrets\brainy-firebase.json.
  5. Open d:\projects\brainy\api\.env and add these two lines: 
    FIREBASE_PROJECT_ID=brainy-6d65c
GOOGLE_APPLICATION_CREDENTIALS=C:\Users\carefull\secrets\brainy-firebase.json
  6. Restart the API: close it, then run node scripts/dev-local.mjs again from d:\projects\brainy.
  7. Install the app on an Android phone, with flutter run or with the APK d:\projects\brainy\brainy\build\app\outputs\flutter-apk\app-debug.apk.
  8. In the app: sign in, open an entry that has a date, tap ⋯ → Reminders, choose Push and tap Allow when Android asks.
  9. Set a reminder for 2 minutes from now and lock the phone. It should ring.

If it stays silent

  • On the phone: Settings → Apps → Brainy → Notifications, check that Rappels / Reminders is on, with sound.
  • Check that the phone and the computer running the API are on the same network, and that the API was restarted after editing .env.
Part 2 · When the API is online on Vercel

Reminders on the free hosting

  1. Create a secret code: run this in PowerShell and copy the result. 
    [Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Maximum 256 }))
  2. In your API project on Vercel, open Settings → Environment Variables and add:
    NameValue
    FIREBASE_PROJECT_IDbrainy-6d65c
    FIREBASE_SERVICE_ACCOUNT_JSONThe entire content of the .json file (open it in Notepad, copy everything, paste).
    CRON_SECRETThe code from step 1. Setting it is what switches reminders on: do not add BRAINY_FROZEN_MODULES, which would also unfreeze the pictures/PDF rule.
  3. Click Redeploy.
  4. Create a free account on cron-job.org.
  5. Click Create cronjob and fill in:
    • URL: https://YOUR-API-ADDRESS/cron/reminders
    • Schedule: every 1 minute
    • Advanced → Headers: name Authorization, value Bearer YOUR-CODE (with a space after “Bearer”)
  6. Save. After a minute or two, the job’s History should show 200 OK. A 401 means the code in the header does not match CRON_SECRET; a 404 means CRON_SECRET is missing on Vercel or the API was not redeployed.
Part 2b · Required for live updates

Real-time synchronisation (Firestore)

Changes made by other people appear without refreshing thanks to Cloud Firestore (free quota: 50,000 reads and 20,000 writes a day). It uses the same Firebase key as Part 1.

  1. In the Firebase console of brainy-6d65c, open Firestore Database → Create database, choose production mode and a European location (for example eur3).
  2. Open the Rules tab, replace everything with the content of firestore.rules (at the root of the Brainy folder), then click Publish.
  3. That’s all: the API already has the key from Part 1. Open the same shared collection on two devices; a change on one appears on the other within about a second.
Part 3 · Optional

Email reminders (free)

If you skip this part, leave the SMTP_ lines empty: only push is used.

Recommended: Brevo (300 emails a day, made for apps)

  1. Sign up at brevo.com.
  2. Under Senders, add and confirm the address reminders will come from.
  3. Go to SMTP & API → SMTP and click Generate a new SMTP key.
  4. Add these lines to api\.env locally, and to the Vercel environment variables: 
    SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_USER=the login shown on that Brevo page
SMTP_PASSWORD=the SMTP key
SMTP_FROM=Brainy <your confirmed address>
  5. Restart the API (or redeploy on Vercel), then choose Email when setting a reminder.

Alternative: a Gmail app password

Also free (500 emails a day), but it uses your personal address and emails land in spam more often. It needs 2-step verification on the Google account; then create an app password at myaccount.google.com/apppasswords and use SMTP_HOST=smtp.gmail.com, SMTP_PORT=587, your Gmail address as SMTP_USER and the app password as SMTP_PASSWORD.

Good to know

  • The Android package name is still com.example.brainy. That is fine for testing; before publishing on the Play Store it must change, and the app must then be registered again in Firebase.
  • iPhone notifications are not set up (they need an Apple developer account).
  • When the app is open on screen, Android does not show the notification banner; it appears when the app is in the background or the phone is locked.
  • Technical details for developers: docs/DEPLOIEMENT_VERCEL.md and docs/tasks/T20.md.
