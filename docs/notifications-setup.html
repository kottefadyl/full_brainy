Brainy on Vercel: notifications, ringing reminders and live updates

Every step below works with Vercel’s free Hobby plan and free services only: Firebase Cloud Messaging and Cloud Firestore (free quota), cron-job.org (free) and, if you want e-mails, Brevo (free). Updated on 12 November 2026.

What the free Vercel plan allows, and what Brainy does about it

NeedFree plan limitHow Brainy handles it
Reminders at the right minuteVercel’s own scheduled tasks run once a day onlyA free outside scheduler (cron-job.org) calls Brainy every minute. Without it, reminders stay switched off.
Live updates between peopleAn open connection keeps a function billable; the free memory quota would run outLive updates go through Cloud Firestore (Google), not through Vercel.
Push notifications that ringAllowedSent through Firebase Cloud Messaging, high priority, with sound.
Pictures, videos, sound, PDF4.5 MB per request; no file storageNever stored. Other files up to 2 MB.
Background processing, data sources, large filesNo process running between requestsSwitched off automatically on Vercel.
Commercial useNot allowed on HobbyPersonal use only until you move to a paid plan.
Already done in the code: the switches above are automatic on Vercel, reminders ring on Android (“Rappels / Reminders” channel, high importance, sound, vibration), and live updates start by themselves once Part 3 is done.
Part 1 · Required

Get the Firebase key

Your Firebase project brainy-6d65c already exists, with the Android app registered. One key is missing: it lets the API send notifications and open live updates.

  1. Open console.firebase.google.com and choose brainy-6d65c.
  2. Click the ⚙ gear, then Project settings, then the Service accounts tab.
  3. Click Generate new private key, then Generate key. A .json file is downloaded.
    This file is a password for your Firebase project. Never send it to anyone and never put it in a Git repository. Keep it in a private folder.
Part 2 · Required

Settings of the API project on Vercel

  1. Create a secret code for the reminder scheduler: run this in PowerShell and copy the result. 
    [Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Maximum 256 }))
  2. In the API project on Vercel (repository api_brainy), open Settings → Environment Variables and add:
    NameValue
    FIREBASE_PROJECT_IDbrainy-6d65c
    FIREBASE_SERVICE_ACCOUNT_JSONThe entire content of the .json file from Part 1 (open it in Notepad, copy everything, paste).
    CRON_SECRETThe code from step 1. Setting it is what switches reminders on.
    Do not add BRAINY_FROZEN_MODULES: it replaces the automatic list and would switch back on features the free plan cannot run, including storing pictures and PDF files.
  3. Open Deployments, click ⋯ on the latest one, then Redeploy, so the new settings are used.
Part 3 · Required

Live updates with Cloud Firestore

Changes made by other people appear without refreshing. Free quota: 50,000 reads and 20,000 writes a day. It uses the key from Part 1; nothing else to set on Vercel.

  1. In the Firebase console of brainy-6d65c, open Firestore Database → Create database, choose production mode and a European location (for example eur3).
  2. Open the Rules tab, replace everything with the content of the file firestore.rules (at the root of the Brainy folder), then click Publish. These rules let a person read only the signals of collections shared with them, and nobody but the API can write.
Part 4 · Required

The reminder scheduler (cron-job.org)

  1. Create a free account on cron-job.org.
  2. Click Create cronjob and fill in:
    • URL: https://YOUR-API-ADDRESS/cron/reminders (your API address on Vercel)
    • Schedule: every 1 minute (every 5 minutes also works and uses less of the free quota)
    • Advanced → Headers: name Authorization, value Bearer YOUR-CODE (with a space after “Bearer”)
  3. Save. After a minute or two, the job’s History should show 200 OK. A 401 means the code in the header does not match CRON_SECRET; a 404 means CRON_SECRET is missing on Vercel or the API was not redeployed.
Part 5 · Required

The Android app and the first ringing reminder

  1. Build the app with your Vercel addresses (in the brainy folder of the project): 
    flutter build apk --release --dart-define=API_URL=https://YOUR-API-ADDRESS/graphql --dart-define=WEB_APP_URL=https://YOUR-WEB-ADDRESS
    The file is build\app\outputs\flutter-apk\app-release.apk; install it on the phone.
  2. In the app: sign in, open an entry that has a date, tap ⋯ → Reminders, choose Push and tap Allow when Android asks.
  3. Set a reminder for 2 minutes from now and lock the phone. It rings.
  4. Live updates: open the same shared collection on the phone and on the web, change an entry on one; it appears on the other within about a second.

If it stays silent

  • On the phone: Settings → Apps → Brainy → Notifications, check that Rappels / Reminders is on, with sound.
  • On cron-job.org, the History shows 200 OK every minute.
  • On Vercel, the three settings of Part 2 are present and the API was redeployed after adding them.
Part 6 · Optional

E-mail reminders (free)

If you skip this part, only push notifications are used.

  1. Sign up at brevo.com (free: 300 e-mails a day).
  2. Under Senders, add and confirm the address reminders will come from.
  3. Go to SMTP & API → SMTP and click Generate a new SMTP key.
  4. Add these variables to the API project on Vercel, then redeploy:
    NameValue
    SMTP_HOSTsmtp-relay.brevo.com
    SMTP_PORT587
    SMTP_USERThe login shown on that Brevo page
    SMTP_PASSWORDThe SMTP key
    SMTP_FROMBrainy <your confirmed address>
  5. Choose Email when setting a reminder.

Good to know

  • The Android package name is still com.example.brainy: fine for testing; before the Play Store it must change and the app must be registered again in Firebase.
  • iPhone notifications are not set up (they need a paid Apple developer account).
  • When the app is open on screen, Android shows no banner; the reminder appears when the app is in the background or the phone is locked.
  • Putting the API and the web online on Vercel (MongoDB Atlas, the two projects): docs/DEPLOIEMENT_VERCEL.md.
